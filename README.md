## 수업에서

교사용 슬라이드는 데이터 수집, 모델 학습, 프로그래밍, 평가, 이동과 화물 검문을 차례대로 안내합니다. 학생은 QR로 입장해 같은 브리핑을 자기 속도로 넘길 수 있습니다. 이어서 플레이할 때는 이 브라우저에 저장된 근무 기록을 사용합니다.

- WASD(ㅈㅁㄴㅇ) 또는 방향키로 걸으며 Shift로 달리고 Space로 점프합니다. 오른쪽 드래그나 Z·C로 카메라를 돌리고 휠로 거리를 조절합니다.
- 운전석에서 E(ㄷ)로 날짜와 사진을 검사하고 Q(ㅂ)로 하차를 요청합니다. 얼굴이 달라졌다면 메디컬 기록을 조회합니다. 위험 화물에는 운전자 신원, 물품 종류, 유효 날짜가 맞는 운송 허가증이 필요합니다.
- 화물칸 옆에서 E로 열고 천이 있으면 한 번 더 눌러 짐을 드러냅니다. 가까이서 실물을 클릭하면 레인저가 짐을 듭니다. 왼쪽 드래그로 짐을 뒤집거나 돌리고, 적재함이나 발밑을 클릭해 내려놓습니다. 도주나 괴물 경보가 울리면 몸통을 가리켜 클릭합니다. 살아 있는 괴물을 발견한 차량은 즉시 보류됩니다.
- 신고서와 실제 화물이 다른 축제 음료·씨앗 화분은 들고 노란 압수함 가까이에서 상자를 클릭하거나 E를 누릅니다. 나머지가 정상이면 운전자는 통과합니다. 유효한 허가가 없는 핵폭탄·괴물 알은 운전자를 포획하고 주황색 레버에서 인계합니다.
- 손목지도 M(ㅡ)으로 감식대를 찾습니다. 6종 × 6가지 모습의 화물에서 표본 이름을 붙이고 색 또는 실제 3D 단면의 치수로 학습합니다. 연습에 나오지 않은 12개로 시험하고 오판을 고칩니다. 직접 통과·보류 판정을 두 건 이상 내리면 결정 트리를 학습해 최대 네 게이트에 같은 새 수송대를 보낼 수 있습니다.
- 타워 부지에서 수입으로 감시 타워를 짓고 필터를 강화합니다. 불허 차량이 실제 게이트를 통과하면 12 CR을 냅니다. 3단계부터 급식 배송단, 의료 귀환단, 연구 표본단에 맞는 필터 조합을 저장해 자동으로 전환할 수 있습니다.
- 4회 운행이 한 주기입니다. 5주기 종료 시 허가증을 PNG/PDF로 저장해 교사가 정한 과제함에 제출합니다. 교사는 [제출 확인 화면](https://207studio-founder.github.io/orbit-gate-academy/receipt.html)에 허가증 번호 여섯 자리를 입력하고 확인 번호를 전달합니다. 학생이 확인 번호를 입력하면 무한 모드가 열립니다.
- 무한 모드에서 타워 16기로 세 그룹의 자동 전환을 켜고 네 번 운행할 때마다 정확도 85% 이상, 위험 차량 오통과 0건이면 운영 성공 한 주기로 셉니다. 네 주기를 성공하면 정비소에서 우주 콘도 회원권을 210 CR로 구입할 수 있습니다.

## 실행과 빌드

루트에서 `python -m http.server`를 실행한 뒤 브라우저에서 로컬 서버를 엽니다. GitHub Pages에는 완성된 정적 파일과 게임 엔진이 포함돼 있습니다.

3D 메시, 이동·충돌, 이벤트, 포획, 장비·경제를 Rust로 구현하고 WebAssembly로 배포합니다. WebGL에서 배경과 움직이는 물체를 두 묶음으로 그립니다. WebGL을 사용할 수 없으면 같은 3D 장면을 Rust에서 직접 그립니다. 브라우저는 입력, 화면, 파일 저장을 담당합니다. 모델 학습에는 학생의 판정과 선택한 특징을 사용하는 이진 결정 트리가 쓰입니다.

```sh
rustup target add wasm32-unknown-unknown
cargo build --release --manifest-path engine/Cargo.toml --target wasm32-unknown-unknown
```

빌드한 `orbit_port.wasm`을 `assets/port.wasm`에 복사하고 `node engine/measure-cargo.cjs`로 메시에서 감식용 단면 치수를 갱신합니다. `node --test engine/*.test.cjs`로 게임 엔진과 학습·운영 규칙을 확인합니다.

## 제작 자료

레인저, 우주 트럭, 화물, 괴물과 나무는 이 게임을 위해 만든 수평 픽셀 단면을 쌓아 표현합니다. 관제 음성 3개와 짧은 효과음 3개는 ElevenLabs로 제작해 게임에 내장했습니다. 사용한 소프트웨어와 글꼴의 라이선스는 `vendor/`에 있습니다.
