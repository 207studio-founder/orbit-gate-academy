# 오르빗 게이트

한국 초등학교 6학년 실과 ‘인공지능이 만들어지는 과정’과 연결한 개인용 우주항 검사·디펜스 게임입니다.

- [학생용 게임](https://207studio-founder.github.io/orbit-gate-academy/)
- [교사용 QR 화면](https://207studio-founder.github.io/orbit-gate-academy/#teacher)
- [QR 이미지](assets/join.png)

## 수업에서

학생이 통행증의 마지막 날을 오늘과 비교하고 얼굴과 짐을 확인합니다. 직접 붙인 통과·보류 판정이 학습 데이터가 됩니다. 단서를 선택해 모델을 학습시키고 두 가지 예측에 게이트 동작을 연결합니다. 같은 새 방문객으로 최대 네 모델을 비교하며 잘못 통과시킨 경우와 안전한 승객을 잘못 보류한 경우를 살핍니다. 운항 기록에서 사례를 다시 검사하고 새 수송대로 재평가할 수 있습니다. 급행 레일은 안전한 짐을 회수해 검사대로 가져오는 선택 활동입니다.

40분 예시로 입장과 안내 5분, 자료 수집 12분, 학습·동작 연결·평가 15분, 생활 속 돌아보기 8분을 배정할 수 있습니다. 수업을 일찍 마칠 때도 수송대 한 번을 마치면 ‘생활 속으로’를 열 수 있습니다.

## 실행 및 구현

정적 파일을 그대로 제공하면 됩니다. 이 폴더에서 `python -m http.server`를 실행하고 로컬 주소를 여세요. 학생 계정이나 별도 API는 필요하지 않습니다. 학생의 판정과 결과는 브라우저의 로컬 저장소에 보관합니다.

검사 화면은 Three.js 단일 WebGL 장면을 사용합니다. WebGL 초기화가 어려운 환경에서는 같은 모델로 미리 렌더링한 방문객과 화물 이미지를 사용합니다. 자동 방어 게이트는 하나의 시계로 최대 네 시뮬레이션을 함께 진행합니다.

날짜 비교, 사진 일치 여부, 두 위험 화물의 형태를 특징값으로 변환한 뒤 학생이 선택한 특징과 판정으로 이진 결정 트리를 학습합니다. 예측 과정은 정답 판정 함수를 호출하지 않습니다. 각 수송대 안에서는 사례를 공유하고, 다음 수송대에는 새로운 방문객을 생성합니다. 보류는 사람의 재검사를 뜻합니다.

## 제작 자료

3D 캐릭터·물건·항구와 인터페이스는 이 게임을 위해 제작했습니다. 표지 우주항 일러스트는 이미지 생성 도구로 제작했습니다. 학생이 보는 사진과 화물 도감은 게임 모델의 렌더링입니다. Three.js의 MIT 라이선스와 Black Han Sans의 SIL Open Font License는 `vendor/`에 있습니다.
